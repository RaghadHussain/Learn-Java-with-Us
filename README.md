# Learn Java with Us

## User Stories

1.	As a User I want to have questions in various levels.
2.	As a User I want to a board that have my results.
3.	As a User I want a timer for each question.
4.	As a User I want to reset the game at any time.
5.	As a User I want to see the right answer if I get it wrong. 
6.	As a User I want at least one chance to rewrite my answer.
